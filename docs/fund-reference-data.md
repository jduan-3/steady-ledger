## 数据和显示

- 腾讯 `qt.gtimg.cn`：快照价格、前收、今开、高低、成交量额、换手率及实际报价时间。此处只解析沪深参考ETF；成交量从手换算为份，成交额使用人民币元。不能沿用这份单位映射解析港股或美股。
- 腾讯分时：保存来源日期和原始时点；量柱为相邻已返回时点的累计成交量之差，午休及缺失时点不补零。参考报价与分时分别保留各自时间。
- 腾讯不复权日线：最近60条，包含开高低收及成交量。当日未完成的日线显示“当日暂计”，不将复权序列冒充原始价格。
- 用户可切换分时与日线，通过时间滑块读取价格、涨跌及量能。资料依据和来源链接在详情中可展开查看。
- 量柱与股票图共用红涨、蓝跌、灰色持平／缺比较价规则。分时比较上一已返回价格，首柱有同日昨收时比较昨收；日线比较上一条收盘，首条缺比较价时为灰色。颜色表示价格变化，不表示主动买卖，来源未提供买卖方向。

## 刷新和读取范围

打开基金详情时先读取本地缓存，再检查更新；详情打开且页面可见时每分钟检查。刷新共用在途请求，服务端一分钟缓存，手动点击也遵守缓存。请求失败或返回旧日期时分别保留已有报价、分时和日线，显示错误及原始日期；缺失数字不补零。行情仅保存在独立的 `fund_reference:` 缓存中。

接口沿用应用登录保护。开启完整页面资料授权后，AI可读取相同缓存：自动上下文只发送报价、图表数量和最新点；完整分时和日线通过 `get_page_data` 的 `instruments/referenceMinutes`、`instruments/referenceHistory` 分页读取。`get_instrument_details` 返回相同摘要。数据抓取、刷新和图表计算不调用模型。

## 验证

使用隔离账本检查参考关系、证券身份、日期、单位换算、累计量差分、缺失值、缓存去重、断网回退、过期数据、登录保护及AI分页。对每次行情刷新核对正式净值、持仓、现金、版本、快照和审计均不变；用浏览器检查桌面和手机详情、周期切换、时间选择与重试。
