# Steady Ledger

A self-hosted personal ledger, portfolio tracker, and conversational finance assistant.

自用的资产、持仓、收支与市场数据工具，支持财务计算和 AI 问答。

中文优先，采用简洁的浅色界面，支持电脑和手机浏览器。使用 Pi Durable 驱动问答，不需要云端账本账户。

公开仓库只包含程序、文档和虚构样例。真实账本、持仓、对话、模型密钥、头像、备份及本机截图保留在各自的本地数据目录，不随源码发布。发布前运行 `npm run check:public` 检查文件与暂存区，详情见 [安全与隐私说明](SECURITY.md)。

## 开始使用

需要 **Node.js 22.19 或更高版本**，建议使用 Node.js 22/24 LTS。应用使用 Node 内置 SQLite；Node 22 可能提示实验性功能警告。

```sh
npm ci --ignore-scripts
npm start
```

打开 [http://127.0.0.1:3210](http://127.0.0.1:3210)。首次访问自行设置至少 8 个字符的访问密码。

无需构建前端。记账与规则日报不需要 API Key；“个人助手”需要自行填写可用的模型连接并授权摘要外发。

首次进入可选择“体验演示”，全部为虚构数据。点击顶部“开始记录我的财务”可确认清空演示后重新建档。演示里没有登记房屋估值，不能把其净资产理解为完整家底。

## 已实现

- 资产与负债：现金、股票、基金、债券、积存金、实物黄金、保证金黄金、保险、其他资产与贷款的新增、编辑和删除；支持按名称、股票或基金代码、账户搜索，并与分类筛选组合。股票可按沪深、港股、美股分别查看，保留当前市值降序及占全部股票组合的比例；按证券交易市场识别，未登记市场的持仓单列。
- 收入与计划：税后收入、必要支出、月供、续期保费、应急目标与未来支出；支出计划可新增、编辑、删除并按日期展示，显示计划金额合计；可选填家庭责任、收入波动、目标和退休计划。
- 总览：净资产、配置资产池、股票敞口、可用现金、储备月数及规则提醒。
- 净资产走势图：展示近 30 天已记录金额，可点选日期；账本调整用虚线标记，缺失日期和不完整估值不连线。
- 个人助手：自然讨论生活、关系、工作、学习与选择，擅长财务分析；按问题决定回答形式，不固定套用财务报告或强行追问。涉及资金时按需使用只读工具；本次现金付款可独立计算余额，不需先定赠与或借款性质，也不把现金够付等同于值得给或负担得起。通过 Pi 按需读取美股、港股市场和个股报价，买入和加仓先计算资金能力与分批安排。
- 每日港美股简报：DeepSeek 等已配置模型根据脚本收集的数据总结，每个市场每个完整交易日自动生成一次；市场页与每日总结页共用本地缓存。
- 真实连接状态：区分未配置、未授权、未验证、已验证和失败；调用失败直接报错并保留草稿，不生成本地替代回复。
- 完整页面资料：可授权 AI 直接读取所有页面的已保存业务数据；聊天中可展开查看 harness 工具的参数、执行状态和完整返回数据。
- 自然语言记账：可根据明确已发生的买卖或收支更新本地持仓与现金。买入未说明资金来源时先询问现有现金还是额外投入；当天收盘价／基金净值未披露时保存待入账记录。
- 日报：按指定时区定时生成站内总结，支持手动重算、离线补生成与可选 AI 解读。当天账本版本改变时提示更新快照；并发生成请求共用一次任务。
- 导入与恢复：资产和负债标准 CSV、预览及按编号替换、JSON 备份、历史版本恢复。
- 访问与数据：密码登录、24 小时会话、服务端加密保存 API Key、外发范围选择。

## 页面使用

界面参考 Notion 的页面与数据库视图：浅灰文字导航、白色内容区、细分隔线、分类标签与行悬停反馈，不展示品牌 Logo 或宣传文案。桌面导航可收起；点击资产名称可查看基金／股票详情或编辑其他资产，原有详情、编辑、删除入口继续保留。资产分类改为完整的占比列表，净资产与行情走势图、PE／股息资料、全部表单和操作保留。

总览、资产页和日报中最醒目的汇总金额默认显示为 `***`，点击金额可显示，再点一次隐藏；单项持仓、价格、比例和明细数字照常展示。显示状态仅保留在当前页面内存中，刷新或重新打开后默认隐藏。

股票与基金分别显示“占股票组合”和“占基金组合”：每项当前估值统一折人民币后，除以对应类别全部持仓估值；包含配置池外持仓，搜索与分类筛选不改变分母，不按成本或基金的股票仓位比例计算。两类分类默认按估值从大到小排列；缺少估值或汇率时占比显示待补齐，已有估值但行情待更新时保留计算并注明。两类组合的估值合计均默认隐藏，点击展示。

点击股票或基金的涨跌数值或图表图标，查看股价／单位净值走势图，可点选日期并展开逐日明细。仅绘制已保存的最多 60 条记录，日期间隔（含休市）以虚线表示。股票详情另有 PE、PB、股息率、每股股息、市值、每股盈利与净资产；基础指标按需从 OpenD 读取，保留来源、时间、原币种和 TTM／上一财年口径，缓存 30 分钟。读取失败时保留旧资料并明确提示；没有的数据不填成零。基金展示已登记份额和持仓累计分红，不套用个股 PE，也不将个人累计分红当成基金每份派息。

现金流、个人背景、AI 连接与纪律设置的未保存修改会在本次页面打开期间暂存，切换页面或设置标签后可继续编辑。保存只清除对应表单的草稿，也可点击“放弃更改”。草稿只保存在当前页面内存中，刷新、关闭页面或退出登录后清除；这不等同于已保存或长期备份。

手机底栏保留财务总览、资产与负债、收入与计划、个人助手 和“更多”。美国市场、港股市场、每日总结和设置从“更多”进入。

“个人助手”参考提供的 Gemini 截图采用居中对话、底部圆角输入框和简洁留白，保留现有财务导航。财务摘要可从右上角“财务背景”展开，模型按钮可直接进入连接设置。私人助手称呼默认留空，可在“收入与计划 → 关于你”修改或留空；已授权的财务摘要会携带这个称呼。演示数据不使用真实称呼。

## 连接模型

进入“设置 → AI 连接”，填写：

1. Base URL，例如 `https://your-provider.example/v1` 或本机服务的 `http://127.0.0.1:端口/v1`。
2. 服务提供的模型 ID。
3. API Key；不需要鉴权的本机模型可留空。
4. 查看外发说明，选择是否允许发送财务摘要；持仓名称、当前对话上下文和自动 AI 日报分别控制。

点击“保存并测试连接”。启用工具时会实际完成一次模型 → 只读工具 → 模型的往返，只使用空白测试档案。仅有文字响应不会被标为工具验证成功；不支持工具的模型可关闭计算工具后使用文字问答。系统追加 `/chat/completions`；聊天与工具连接验证支持 SSE 分段响应，纯文字连接测试使用普通 JSON 请求。提供商忽略流式参数而返回 JSON 时，收到完整内容后显示，不伪造逐字输出。不保证所有提供商兼容。接口依据 [官方 Chat Completions 参考](https://developers.openai.com/api/reference/resources/chat)。

模型请求从服务端发出。密钥加密存于服务端，不回传浏览器。修改 URL、模型、密钥或工具开关后，原连接验证失效。没有配置或授权时不调用模型；失败不会冒充 AI 成功。

“允许 AI 读取全部页面业务资料”开启后，每轮自动发送完整当前资产、负债、账户名称、备注、成本与盈亏、现金流、个人背景、投资纪律，以及总览、港美股市场、宏观、情绪、行业、估值与股息等最新可用页面数据。金额在界面中隐藏或列表被筛选，不影响已经授权的读取范围。图表历史和日报归档保留完整的只读入口，模型可用 `get_page_data` 按页面、栏目和分页读取；`get_instrument_details` 使用页面相同的股票基础资料来源。资料以本轮开始时的快照为准，新的提问读取新的快照；按需更新的行情另带实际时间。未保存的表单草稿、登录密码、API Key、密钥文件不进入页面资料上下文。对话上下文仍遵循当前对话的独立开关。完整资料授权变更后，原对话保留可查看，新建对话使用新范围。

工具调用时会在回复中显示可展开的名称、参数、执行状态和返回数据，计算工具、页面读取和行情工具都适用。已完成回答的工具明细随该条历史保存；浏览器重连和进程重启可以恢复，不展示模型的内部思考。旧回答没有保存的工具结果不会补造。

工具默认收成一条小提示，正文直接回答结果，需要时再展开明细。在 AI 设置中开启“允许 AI 根据我的明确指令更新本地持仓和现金记录”后，可以说“今天加了 1000 元科创”“卖出科创 20 份”“收到一万元红包”。买入未说明资金来源时必须先问现有现金还是额外投入，确认后才登记；现有现金买入会联动扣减指定账户，额外投入直接增加持仓而不扣原有现金。卖出回到明确的同币种现金账户，红包等独立收支另外记入现金；多持仓、多账户或币种不明确时追问，不猜测换汇。

同一对话中，紧接追问补答“今天买的”或“现有现金”等日期、资金来源，可以接回原来尚未完成的那笔买卖，无需重说完整指令；服务端只合并完整用户原话，已入账或已保存待入账的记录不因补答再次登记。日期按说出该日期的那一轮计算，之后跨午夜补答资金来源不会改成下一天。“买了1000的科创基金”支持金额口语简写；“几天前”等含糊日期仍先追问。

校准已有持仓使用 `set_holding_balance`，直接设置用户确认的总份额／总股数和单位成本；现金变化单独确认，不从份额差额推算交易、成本或扣款。可以连续补充总份额、确认更新、再说明“现金 -1000”或“现金不动”。服务端只承接同一笔尚未完成的更新，不继承助手推算的数字；持仓、成本和现金在一个事务中提交。

金额和数量二选一；用户给出成交价时按成交资料记录，否则按指定交易日的收盘价或基金披露净值估算，明确标为估算并可后续校正。场外基金使用单位净值，未披露前不挪用昨日净值。待入账期间持仓、成本和现金均不变，取得对应日期净值后才一并更新。待入账记录在资产页和收入页可查看、取消；服务每分钟在行情更新后尝试处理，重启后继续。期间持仓已被人工修改、现金不足或授权变化时暂停核对。持仓、成本、现金、快照、审计及入账凭据在同一 SQLite 事务中提交，同一问题重放不会重复记账；已入账的财务变动可用“最近修改”恢复。讨论建议、假设和举例不入账；该能力不连接券商或执行真实交易。

服务端使用完整用户原话核对动作、数字用途、单位和币种；模型截取证据时也不能省掉否定词或币种。“没有买入”等否定指令不落账，“100份、成交价2元”不能被工具改成“100元”，美元收入不能进入人民币账户。单位、用途或币种冲突时拒绝写入并要求核对。未说明币种的普通现金金额仍使用人民币；外币金额、价格和费用需明确币种。清空财务档案会在同一事务中取消旧待入账记录并更新记账代号；清空前已开始查价、尚未提交的任务也不能回写，进程重启或恢复旧快照不会重新激活已取消的待办。

### Pi harness

采用 [官方 Pi Durable](https://github.com/earendil-works/pi/tree/main/packages/durable) 的 `@earendil-works/pi-durable`、`pi-ai` 和 `chord` 1.4.0（2026-10-26 核对 npm latest）。上游仍标为实验性，因此使用精确版本。Durable 负责对话循环、参数校验、工具生命周期和检查点；项目自己的 Chat Completions 适配器继续连接已配置的模型服务，不读取全局 Pi 登录或环境密钥。思考模型的续接字段会进入本机的运行检查点，供重启恢复使用，不发送给前端或写入可见聊天记录。

工具包括 `assess_financial_action`（财务前后变化）、`get_stock_budget`（谨慎线额度）、`get_stock_funding_plan`（新建仓和加仓资金安排）、`get_market_data`（指定日期的港美股数据与简报）和 `get_stock_quote`（按需查报价）。默认只读；明确开启自然语言记账后，聊天另外提供 record_holding_change、set_holding_balance 和 record_cash_flow。本地写入通过原子凭据去重，没有文件、Shell 或真实证券交易工具。市场缓存、简报和聊天结果保存在本地 SQLite。进行中的问题使用 `data/assistant-runs/` 下权限为 0600 的 SQLite 检查点，保存冻结的本轮上下文、模型轮次和工具结果；浏览器断线不停止生成，刷新或重新连接会接回同一轮回答。进程重启后恢复尚未完成的任务，已完成工具不重放，中断的只读工具可以安全重放；正在进行且尚未提交的模型请求可能需要重新发起，不承诺按 token 原地续传。明确点击“停止回答”、删除对话或修改授权范围会终止任务，不再恢复。最终回答原子写入原聊天表后清理运行检查点；重复提交相同 requestId 不重复调用模型或保存回答。密钥继续仅存于原有加密配置，不写入检查点。记账工具确认缺信息后，harness 直接用具体缺项生成追问，结束本轮并等待补答，不再让模型改写证据反复尝试。参数与用户已明确提供的数字不符时，只应用服务端从原话核对出的参数修正，再完整校验；不会用助手生成的数字补空缺。每轮最多 5 次模型请求、8 次计算，单请求默认 120 秒、整轮默认 360 秒上限。响应等待时间可在 AI 设置中调整为 10–300 秒，整轮上限为单请求的 3 倍；超时与域名解析、连接中断、鉴权失败分别提示。数据变化后下一次提问会注入最新快照，旧回答保留原快照版本。

个人助手左侧支持查看、切换、新建和单独删除历史对话。开启“携带当前对话上下文”后，只发送当前对话最近最多 6 轮、24,000 字符的成功问答，新建对话从空白开始。新配置默认开启上下文，已有关闭设置保留。切换上下文开关会停止正在回答的任务，仍可继续使用原对话。更换模型、密钥或资料授权范围后，旧历史仍可查看和删除，继续讨论需新建对话。设置中的“删除全部对话”会清除所有对话记录。旧版本的本地规则回复不进入新问答上下文。聊天先显示思考状态，计算时提示正在核算，通过 SSE 持续显示回答，按纯文本处理 Markdown 标记。停止回答会取消上游请求；断线或中止时保留临时文字和问题草稿，只有成功完成的对话才写入历史。

## 计算口径

基准币种为人民币。外币估值使用用户在设置中填写的汇率，缺汇率或估值时保留缺口；配置池内资料缺失时不给出精确配置比例，池外缺口仍会标明总资产不完整。

| 指标 | 定义 |
| --- | --- |
| 净资产 | 已登记总资产 − 已登记总负债；负的保证金账户净权益作为负债。 |
| 配置池净值 | 纳入配置的金融资产，减应急、专项预留及关联投资借款。房产、车辆等其他资产排除，保险默认排除但可选择纳入。 |
| 股票比例 | 同一配置池内的股票敞口 ÷ 配置池净值。基金单独统计，不按内部股票占比折算为股票。 |
| 可支配现金 | 非受限现金，减应急与专项预留。AI 计算目前只使用人民币现金，股票买入限配置池内现金。 |
| 月度经常性结余 | 税后经常性收入 − 已登记生活开支 − 未计入开支的续期保费月均额 − 每月债务偿还。缺月供时不按零处理。 |
| 月供收入比 | 月供 ÷ 税后经常性收入；不是银行常用的税前授信 DTI。 |
| 必要支出储备月数 | 非受限现金减专项款，除以必要支出与月供；可包含预留应急金。 |

股票比例严格超过 50% 时触发初始谨慎线。其他上限默认不启用。应急储备初始建议为 6 个月，可自行修改；这些是产品或用户规则，不宣称是格雷厄姆原著的全部要求。

比例分母包含黄金等产品，属于现代适配，并非原著纯股债比例。不把高股息、黄金或所有债券自动当成无风险资产；不为满足股票下限而强迫投资。第一版不做原著七项个股筛选，也不会因为配置检查未触发就推荐购买。

### 加仓资金与价格网格

在“设置 → 纪律与偏好”调整每笔比例与网格。“默认每笔买入占配置池”按当前配置池净值（含可投资现金）计算；设置后优先于等额分批数，并受剩余现金、股票总仓位、单一发行人额度和本轮预算限制。同一公司的 A/H 持仓合并检查发行人上限。该比例留空时，初版仍为四笔等额、每格 5%，支持无股息股票；不倍投、不追补一次跨过的多格，也不把建议当作成交。已有持仓暂用平均成本作为参考，工具会标明参考价，用户可指定本轮锚点。没有已确认成交记录时，不推断格子已执行。参数为可调整的草案，不代表最优策略或收益保证。

资金工具使用已登记的仓位上限（未设置时退回谨慎线），扣除应急目标缺口、专项款未覆盖的近期支出和临近保费，仍未确认的投连险股票敞口按上界计算；基金与股票分开统计。仅规划现有人民币配置现金，外币金额是换汇计划；不把券商购买力、未来收入或保险价值当作现款。不完整估值、未知月供或保费会阻止精确的正额度；交易费用需另留余量。香港整手股数只在获得有效每手股数时计算。

### 每日市场简报

市场页指数、行业和持仓使用最新可用行情快照，附实际数据源和时间；页面打开时每分钟检查一次，不保证逐笔实时。行情摘要按固定栏目自动提炼：美股为市场主线、行业广度、行业强弱及有效波动情绪；港股为市场主线及科技／国企相对恒指的分化。缺失栏目省略，VIX 与 CNN 未取得或跨日时不展示。完整交易日收盘记录继续用于历史和每日简报；历史与情绪数据每 30 分钟检查，行情轮询不重复调用模型。

在 AI 连接设置中启用自动简报。脚本持续收集 OpenD 与公开接口的指数、行业 ETF 和持仓行情；每日简报模型只接收公开市场数据，负责简短中文归纳，不接收或描述个人持仓、个股表现及个人盈亏，不额外搜索新闻或猜涨跌原因。以市场最近完整交易日为键，美国和香港分别生成，休市复用；固定栏目与行情摘要一致，遗漏应有栏目则不接纳该模型结果；每次不超过 550 输出 token；官方 DeepSeek Flash/V4 Pro 连接为短简报关闭思考模式，聊天工具循环保持原设置。生成失败等待手动重试，普通刷新不会重复调用；“重新总结”会明确发起新请求。简报最多保留 120 个市场/日期记录，指数历史用于回答已有日期；没有历史资料时如实返回可用日期。应用需要持续运行，重启后复用已保存的简报。每日市场简报始终仅发送公开数据；问答工具的个人持仓外发范围另遵循 AI 授权设置。

美股页另有巴菲特指标：脚本获取美联储 Z.1 公开交易股权市值和 BEA 同季度年化名义 GDP，统一单位后计算比值；显示季度、原始金额、计算口径与来源。成功每 24 小时检查，失败每 30 分钟重试；缺失或过旧时隐藏。格式与公式详见 [行情摘要固定格式](docs/market-summary-format.md)。

### 保险资产

储蓄险、年金险、投连险和保障险均可登记。`value` 只填写当前现金价值、账户价值或退保净值，保额、累计已缴保费和可领取金额单列，不重复加总。未知价值留空；确认没有价值才填 0。保险计入已登记总资产，但不计入可支配现金，默认在配置池外。纳入池内的投连险需要股票占比，未知时按区间展示。现金价值与保障金额是不同概念，参考 [NAIC 寿险消费者说明](https://content.naic.org/consumer/life-insurance.htm)。

续期保费可选择月、季、年、一次性已缴或已缴清。只有明确未包含在生活开支中的续期保费才追加月均支出；金额或汇率未知时，结余保留“待补充”。缴费日期在未来 30 天内或已经到达时提示核对实际缴费状态，不擅自推断保单失效。月均计提不代表缴费日已有现金。

### AI 了解你的哪些背景

“收入与计划 → 关于你”提供可选字段：希望 AI 使用的称呼、个人或家庭账本口径、年龄阶段、供养人数、低收入月份收入、退休距离、主观可接受亏损、保障概况、目标与用钱时间、家庭责任及特殊约束。不了解的可留空，不要求完成问卷后才能提问。结构化字段用于更有针对性的追问，不自动生成新的投资阈值；愿意冒险不等于有能力承受损失，填写保障类型不代表保障充足。

不收集身份证、账号、保单号和精确住址。字段随明确授权的财务摘要外发；“家庭责任”可描述持续赡养、教育、自营收入集中、连带担保等情况，无需填身份或健康隐私。近期明确金额与日期的资金需求另登记在支出计划中，避免只写在备注里。

### 示例

股票 45,000 元、配置现金 55,000 元：用现有现金买入 10,000 元，股票比例从 45% 变为 55%，池净值仍为 100,000 元。若是借款买入，必须同时登记债务，不能用借款稀释风险。

收入 30,000 元、必要开支 10,000 元、现有月供 12,000 元：新增车贷月供 9,000 元、用车开支 3,000 元后，月结余由 8,000 元变为负 4,000 元。该情景会明确提示现金流缺口。

## CSV 导入

在资产页分别下载资产和负债模板。文件采用 UTF-8，兼容 BOM 和带引号的逗号字段。

- 资产必需列：`name,type,currency,value,asOf`。保险 `type=insurance` 时 `value` 可为空，其他资产需填写估值。
- 负债必需列：`name,currency,balance`，建议填写 `payment` 月供。
- 推荐始终保留稳定的 `id`。相同编号替换已有记录，其他记录保留；同一文件重复导入不会翻倍。
- 不提供 `id` 时，按照账户、币种、类型和名称生成稳定编号；改名会被视为另一条记录。
- 一个文件内编号重复会报错。请勿混入账户合计行，逐条预览再确认。
- 删除记录需要在页面操作；不通过文件缺行猜测删除。

保险扩展列：`insuranceKind,valuationBasis,sumAssured,paidPremiums,accessibleValue,premiumAmount,premiumFrequency,premiumInExpenses,nextPremiumDate`；枚举与示例见 [保险示例](examples/insurance.csv)。

参见 [资产示例](examples/assets.csv)、[负债示例](examples/debts.csv) 与 [完整虚构备份](examples/demo-backup.json)。

## 自托管与备份

```sh
docker compose up -d --build
```

Compose 默认只将端口绑定到本机 `127.0.0.1:3210`，数据保存在 `balance-data` 卷中。若需要从其他设备访问，请在自有 HTTPS 反向代理后部署，并保留密码登录。首次设置密码应在你控制的环境中完成。

| 环境变量 | 默认值 | 用途 |
| --- | --- | --- |
| `HOST` | `127.0.0.1` | 监听地址，容器内为 `0.0.0.0`。 |
| `PORT` | `3210` | HTTP 端口。 |
| `DATA_DIR` | 项目 `data/` | SQLite 和本机密钥文件目录。 |
| `TRUST_PROXY` | 关闭 | 仅在可信 HTTPS 代理后设为 `1`，用于 Secure 会话 Cookie。 |
| `APP_PREVIEW` | 关闭 | 开发时 `1` 可跳过登录，只允许本机回环地址，务必使用独立虚构数据目录。 |

普通 JSON 导出只包含财务档案、保险与个人背景、纪律及旧版决定记录；不包含 API Key、访问密码、会话、对话、日报或完整审计历史。恢复后应重新生成今日报告。

完整迁移时，停止服务后复制**整个数据目录**，其中 `secret.key` 用于解密数据库内保存的模型密钥，应与数据库一起妥善保管。该方案不能防护同时获得数据库与密钥文件的主机管理员。目录、数据文件及密钥均已加入 Git 忽略规则。

数据不会默认上传到统计或云端账本服务。启用外部模型后，授权的摘要及问题会发送给配置的提供商；在对方服务中的留存取决于其政策。

## 日报与数据时效

日报是站内报告，尚未接入邮件或企业微信等外部推送。服务运行时按分钟检查指定时区的生成时间；离线错过时间后补生成最近一期，标明补生成，同一天不重复创建。

股票、基金和汇率支持自动同步，也可使用手工记录；具体来源、回退与更新频率见后文。市场页先展示本机已缓存数据，再尝试更新；失败时保留数据与重试入口。没有更早快照时不画历史收益；有快照时只展示估值差额，不把储蓄、贷款变化或修正当成投资收益。关键资料缺失时保留缺口。

## 在自己电脑上使用

运行 `npm run local`，访问 http://127.0.0.1:3211。这个入口固定只监听本机回环地址，使用正式的 `data/` 账本，不需要 ChatGPT 登录。原来的 `npm run preview` 仍使用隔离的虚构演示账本，二者使用同一端口，不能同时运行。需要在局域网或服务器上使用时继续运行 `npm start`，保留访问密码保护。

场外基金可填写六位代码、持有份额并勾选自动净值。服务运行时每分钟检查任务，成功净值最多每 30 分钟请求一次，失败后 5 分钟重试；“更新净值”可重试失败项。只请求公开代码，不向行情来源发送份额或账本。来源为天天基金披露的单位净值，不使用累计净值或盘中估算；失败时保留已有估值并显示待更新。基金和 QDII 净值可能延迟，界面保留实际净值日期。

“基金净值日变动”按当前份额乘前后两个披露日的单位净值之差估算，不含买卖和现金分红。“较昨日净资产”需要前一日完整快照，首日不编造变化；出入金和持仓补录属于账本变动。保险按已确认保单价值计入资产，不当作可支配现金，缴费周期未知时保留待确认。

本机休眠或服务退出时不能抓取净值，恢复运行后检查最新披露净值。`data/`、数据库及密钥均被 Git 忽略；备份时应同时保留数据库和密钥文件，并妥善保管。

本地个人头像保存在 `data/profile/avatar.jpg`，通过受登录保护的接口读取，不放入公开静态文件或财务 JSON 导出。迁移头像时需另外保留该文件。


## 本地股票行情与涨跌记录

股票输入名称或代码即可搜索，结果显示交易市场和币种；A 股与港股的中国平安分别保存，不混用价格。搜索使用腾讯证券公开搜索，本机 OpenD 股票目录和已保存的结果作为备用。行情同时读取本机 OpenD 和腾讯证券公开报价，核对代码及交易日期后保留时间较新的有效报价。休市保留最近交易日数据；来源都失败时保留旧值并显示待更新，不补成零值。

股票每 5 分钟检查，基金每 30 分钟检查；页面打开时每分钟刷新资产列表，编辑和个人助手 时不会打断输入。股票／基金显示最近交易日／披露日的涨跌幅，以及按当前股数／份额估算的金额。点击涨跌数字或图表按钮可查看本地保存的历史记录，红色上涨、绿色下跌，并同时使用符号和正负数。记录包含数据日期和来源，不把休市当作零涨跌，不把持仓补录或累计分红当成当日收益。

本机安装 Futu Python SDK 可用 `python3 -m venv .venv` 后，在虚拟环境安装 `scripts/market-requirements.txt`，通过 `STEADY_MARKET_PYTHON` 指定解释器。macOS 会优先使用已有的 Steady 行情虚拟环境。SDK 只调用证券目录、报价和历史 K 线，不读取券商持仓、资金，也不交易。参考：[OpenD 报价字段](https://openapi.futunn.com/futu-api-doc/quote/get-market-snapshot.html)、[不复权历史 K 线](https://openapi.futunn.com/futu-api-doc/quote/request-history-kline.html)。腾讯证券是公开网页数据来源，接口可能变化；数据日期、缓存和备用来源用于应对中断。


记录股票／基金不需要买入日期或录入日期，代码与股数／份额用于自动计算市值。手工估值日期收在“补充信息（选填）”，留空按本次记录；行情交易日／基金披露日始终取自来源，不用录入时间替代。

“成本与盈亏”是选填项，可填写持仓总成本，或用当前浮动盈亏与当前市值反推成本。已有可靠报价时可按份额算出市值，无报价时需补当前市值。累计浮动盈亏不含现金分红，与当日涨跌分开展示；缺成本不显示假收益。修改份额后应更新这笔持仓的总成本。旧截图的浮动盈亏只有在金额与原始持仓一致时才用于反推成本，补录份额不沿用旧成本。


## 基金盘中参考

在资产页点击基金名称或“详情”，可在净值走势下方查看目标 ETF／同指数参考 ETF 的盘中参考：快照价格、涨跌、今开与高低价、成交量额、换手率，以及分时和最近60条不复权日线。时间滑块可查看来源时点的数据；未收盘日线标为暂计，缺少的数据不补零。参考关系与来源可在详情中展开。

## 股票行情详情

资产页的股票详情新增沪深 A 股、港股和美股的报价、今开高低、成交量额、可用换手率、分时和最近60条不复权日线。成交量统一为股，价格和成交额保留 CNY／HKD／USD 原币，来源时间分别按上海、香港和纽约展示。美股分时只展示常规交易时段；来源延迟标记会显示，缺失成交额不估算。原有 PE、股息资料来源保持独立。详情可见时每分钟检查，使用独立缓存，失败保留实际日期和旧数据。开启完整页面资料授权后，AI 可读取行情摘要，并通过 `instruments/stockMinutes`、`instruments/stockHistory` 按需分页读取完整图表。详见[股票数据口径](docs/stock-market-data.md)。

基金参考与股票图的成交量柱统一红涨、蓝跌、灰色持平或缺少比较价。分时比较相邻已返回时点价格，首柱有同日昨收时与昨收比较；日线比较上一条收盘，缺比较价时用灰色。图例及柱上提示说明比较基准，颜色不表示主动买入或卖出。当前行情来源未提供主动买卖方向，不拆分买量／卖量。

## 美国市场与港股市场

“美国市场”下的“美股行情”以桌面卡片展示预设观察样本，包含热门关注、ETF、信息技术、通讯服务、非必需消费、必需消费和金融，按组内涨跌幅排序。可切换当前行情／最近收盘、搜索名称或代码、查看卡片详情及复制筛选后的行情。报价每分钟检查，逐项保留来源时间；最近收盘只接纳已完成交易日，数据缺失或更新失败时保留缓存，不以零替代。最新行情不推算盘前盘后报价；日 K 线备用的收盘变化使用不复权价格，拆并股或除权会影响比较。标识静态保存在本地，来源与许可证见 `public/logos/LICENSE.txt`，没有标识的证券使用代码。AI 的完整页面授权包含该页，可用 `get_page_data` 读取完整卡片列表。

桌面侧栏的“美国市场”可展开“纳指月度表现”：展示最近三个自然年、12 个月的纳斯达克综合指数涨跌热力图，以及每个月的上涨率、中位数、平均值、最好与最差月份和有效样本数。数据读取腾讯证券公开月线，按相邻月线收盘点位计算价格回报；本月暂计不进入月份统计，缺失月份不补零。进入子页时先显示本地缓存再检查更新，成功数据缓存 6 小时，也可手动更新。开启完整页面授权后，AI 可读取同一份月度数据。该子页为桌面布局。

侧栏提供两个独立市场页面：美国展示标普 500、道琼斯、纳斯达克综合指数、11 个大行业和 16 个细分主题 ETF、VIX，以及宏观和成交活跃度；港股展示恒生、恒生国企、恒生科技指数、港元拆息及成交活跃度。市场页不再绘制个股当日涨跌图；美股和港股持仓复用资产页的股票表格，统一展示资产名称、当前估值、占股票组合、浮动盈亏、最新涨跌、数据日期及操作，组合占比仍按全部股票持仓计算。美国行业表现包含 27 个观察板块：11 个大行业和 16 个细分主题，分别使用拼接方块展示；两组共用颜色刻度，红涨绿跌，不把方块面积解释为行业市值。细分主题包括半导体、软件、互联网、网络安全、云计算、机器人与 AI、生物科技、医疗器械、区域银行、保险业、住宅建筑、零售业、航空业、航空航天与国防、油气开采和金矿股，大行业和细分主题均使用对应美股上市 ETF 的最新公开报价，并显示各自日期；部分基金覆盖全球公司。细分主题与大行业有成分重叠，行情摘要及每日简报仍用原有 11 个大行业计算广度；新增细分主题不会推进指数摘要日期。指数、行情摘要、行业和持仓表现使用最新可用快照，逐项显示来源日期和报价时间。指数走势图保留最近最多 30 个交易日的收盘记录；更新交易日的快照以虚线附加，可点选查看，盘中点不写入收盘历史。完整交易日的每日简报保留在“最近收盘简报”中展开查看。

页面中的“昨日”按来源中最近完成的交易日理解，周末和假期保留实际日期。能读取 OpenD 交易日历时使用其半日市标记；没有日历时保守地等到当地正常收市后 15 分钟才接纳当日 K 线。盘中快照不充当上一交易日收盘，缺历史不绘制虚构走势，缺持仓行情不按零收益处理。持仓日变动按当前股数估算，不能代表持仓期间实际收益。

市场页打开时每分钟同时检查该市场的指数、行业 ETF 和已登记股票持仓；手动更新最多每分钟一次。收盘历史、交易日历和情绪数据每 30 分钟检查，完整更新失败后 5 分钟重试。持仓金额只合计与页面交易日一致、前收盘价有效的报价，同时显示覆盖项数；旧日期或缺失报价显示待更新，不算作零。缓存和实际来源保存在本机 SQLite 的 `markets_snapshot` 项内，不修改财务档案；页面快照也不触发 AI 简报重新生成。休眠或退出后不更新，恢复运行后补抓。

OpenD 使用 `get_global_state`、`request_trading_days`、`get_market_snapshot` 和 `request_history_kline`，只调用行情接口。OpenD 当前不支持美股指数，三大指数使用腾讯证券公开行情补充；港股指数、美国行业 ETF 和登记持仓同时核验 OpenD 与公开报价，保留时间较新的有效值。快照按每批 20 项请求，兼容港股 BMP 的批量限制。腾讯日 K 线提供历史备用，不复权；公开接口可能调整或限流，失败保留已保存的数据。页面显示交易日、来源时间、覆盖数和旧数据状态。行业 ETF 只是行业价格表现的观察样本，不当成全市场涨跌家数。

CNN Fear & Greed Index 使用 CNN 页面公开数据源，按源分数展示 0–100，不通过 OpenD 推算，不使用 AI 或第三方估算冒充 CNN。CNN 可能以 HTTP 403/418/429 限制自动请求；此时显示获取失败，已有读数保留并注明日期。CNN 不可用时不生成替代分数。定时获取、指数图表与规则文字复盘均不调用模型、不消耗 AI token。

来源与复现：[OpenD 全局状态](https://openapi.futunn.com/futu-api-doc/quote/get-global-state.html)、[OpenD 历史 K 线](https://openapi.futunn.com/futu-api-doc/quote/request-history-kline.html)、[CNN 指数页面](https://www.cnn.com/markets/fear-and-greed)。实现与公开请求参数见 `src/markets.mjs` 和 `scripts/opend-local.py`。


### 宏观、金融压力与成交量

市场页新增 2 年与 10 年期美债收益率、10 年减 2 年利差、ICE BofA 高收益债 OAS（FRED CSV），以及美国财政部 OFR 全球金融压力指数。OFR 的 0 为历史平均压力，不是 0–100 贪婪指数。港股页读取金管局的隔夜、1 个月、3 个月 HIBOR 定盘数据，以及贴现窗活动前银行体系总结余；总结余按百万港元转换为亿港元，不解释为南向资金流。逐项保留观测日期、前次观测日期、来源和最近最多 60 次有效观测；来源可能滞后披露，超过 7 个自然日注明滞后天数。

宏观来源独立缓存：成功每 4 小时检查、失败每 30 分钟重试；网络中断或服务端错误最多额外重试一次，失败保留旧值并注明。未取得的数据放在折叠说明内，不画空图或补零。市场快照分钟轮询不重复抓取宏观来源，也不增加模型调用。

成交活跃度样本为 SPY、QQQ、IWM、盈富基金（02800）及恒生科技 ETF（03033）。成交股数与成交额直接读取 OpenD；量比仅计算“最近完整交易日成交量 ÷ 此前 20 个完整交易日平均成交量”，不含当日，缺任一前期成交量则不给量比。盘中累计量单列时间，不与全天均量相比。样本量不代表全市场成交量或净流入。

资产走势图默认从最近一次明确的账本版本调整后起算，可切换近 7 天与 30 天全貌。纵轴只按当前窗口内的实际波动缩放，取消按资产额 4% 撑开刻度的下限；刻度以人民币金额展示。缺日和不完整估值不连线，完整窗口仍用虚线标出账本调整；历史估值变化不等同投资收益。


### 工资自动入账与基金独立统计

“收入与计划”可启用工资自动入账，选择人民币现金账户及起始日期。每月按已登记的税后月收入、发薪日及账本时区记入现金；起始日期前的发薪日不追补。日期超过当月天数时按月末处理。应用运行时每分钟检查，启动时立即检查；离线错过的月份在恢复后逐月补记。账户不可用或月收入不大于零时暂停，页面显示原因。

现金更新、账本版本、快照、审计和按月入账凭据在同一 SQLite 事务内提交。同一个月只记一次；备份中的最近入账月份随财务档案保留，恢复到新数据库后不会重复增加现金。“收入与计划”显示下次入账日及最近 12 笔工资记录。此功能仅更新本地账本，不连接银行。

股票和基金在资产分类及配置比例中分开统计。基金不再因内部股票占比缺失而产生提醒，也不再折算进股票仓位及买股额度的股票敞口；旧备份的基金 equityRatio 字段保留兼容但不参与计算。基金估值和基金占比仍使用同一配置池分母，缺估值或汇率时继续保留缺口。投连险原有规则保持不变。

股票和基金的成本录入支持平均单位成本、持仓收益金额、持仓收益率或总成本任选一种。单位成本乘数量得到总成本；收益金额按同一时点持仓金额减收益反推；收益率按持仓金额除以 1 加收益率反推，不能使用小于等于 -100% 的收益率。截图百分比四舍五入时反推成本是估算，优先使用精确的收益金额。

手动确认基金持仓金额时，可在收益金额或收益率方式中勾选“同时用上述持仓金额校准当前估值”。该金额与数量、确认日期、当时的净值日期一起保存；同一份数下，旧净值不会立即覆盖手动金额，并单列公开净值计算值。取得更新日期的公开净值后恢复自动估值；份数变更后旧校准失效。手续费未知时不凭差额额外补扣。
